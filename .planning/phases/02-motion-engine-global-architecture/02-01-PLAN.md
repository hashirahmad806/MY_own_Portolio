  <action>
    Create src/scripts/motion.ts as a TypeScript client module:

    1. Import Lenis from 'lenis' and gsap + ScrollTrigger from 'gsap/ScrollTrigger'.
    2. Register ScrollTrigger: `gsap.registerPlugin(ScrollTrigger);`
    3. Detect prefers-reduced-motion:
       ```ts
       const prefersReducedMotion = window.matchMedia('(prefers-reduced-motion: reduce)').matches;
       ```
    4. Conditionally initialize Lenis only if NOT reduced motion:
       ```ts
       const lenis = new Lenis({
         duration: 1.2,
         easing: (t: number) => Math.min(1, 1.001 - Math.pow(2, -10 * t)),
         smoothWheel: true,
         touchMultiplier: 2,
       });
       ```
    5. Sync Lenis with GSAP — both critical lines, must not be omitted:
       ```ts
       lenis.on('scroll', ScrollTrigger.update);
       gsap.ticker.add((time: number) => { lenis.raf(time * 1000); });
       gsap.ticker.lagSmoothing(0);
       ```
    6. Export lenis instance as default export so other scripts can call lenis.scrollTo() for programmatic scroll.
    7. If prefersReducedMotion is true: skip Lenis init entirely, disable all GSAP duration/transition.
  </action>
  <verify>Check TypeScript has no errors by confirming npm run build succeeds after this file is added.</verify>

  </acceptance_criteria>

    Create src/components/ui/CustomCursor.astro:

    HTML: Two concentric divs — `#cursor-dot` (small 8px filled dot) and `#cursor-ring` (larger 36px ring outline).

    CSS scoped to the component:
    - Both elements: `position: fixed; pointer-events: none; border-radius: 50%; z-index: 10000; transform: translate(-50%, -50%);`
    - `#cursor-dot`: `width: 8px; height: 8px; background: var(--accent); mix-blend-mode: difference;`
    - `#cursor-ring`: `width: 36px; height: 36px; border: 1.5px solid rgba(237,235,230,0.5); transition: width 0.2s, height 0.2s, border-color 0.2s;`
    - `.cursor-hover` state on ring: `width: 54px; height: 54px; border-color: var(--accent);`
    - Hide on touch devices: `@media (pointer: coarse) { #cursor-dot, #cursor-ring { display: none; } }`

    Client script:
    - Use GSAP quickTo for hardware-accelerated smooth cursor tracking:
      ```ts
      import gsap from 'gsap';
      const dot = document.getElementById('cursor-dot');
      const ring = document.getElementById('cursor-ring');
      const moveDot = gsap.quickTo(dot, "css", { duration: 0.1 });
      const moveRing = gsap.quickTo(ring, "css", { duration: 0.3, ease: "power3.out" });
      window.addEventListener('mousemove', (e) => {
        moveDot({ x: e.clientX, y: e.clientY });
        moveRing({ x: e.clientX, y: e.clientY });
      });
      ```
    - Add/remove cursor-hover class on interactive elements:
      ```ts
      document.querySelectorAll('a, button, [data-cursor-hover]').forEach(el => {
        el.addEventListener('mouseenter', () => ring.classList.add('cursor-hover'));
        el.addEventListener('mouseleave', () => ring.classList.remove('cursor-hover'));
      });
      ```
    - Only init if pointer is fine (desktop): `if (window.matchMedia('(pointer: fine)').matches) { ... }`
  </action>

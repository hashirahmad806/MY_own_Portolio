# Hybrid Hero Stage Telemetry & Physics

We decided to layer parametric SVG orbital guide curves and live mathematical telemetry readouts (`coord-small-xy`, `coord-ring-xy`) directly over the interactive HTML5 canvas Newtonian particle collapse simulation. This provides the exact celestial HUD aesthetic of [gravity-design.de](https://gravity-design.de/) while preserving tactile particle physics and spring equilibrium recovery upon interaction.

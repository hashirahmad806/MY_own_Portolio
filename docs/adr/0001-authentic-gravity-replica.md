# Authentic 100% Gravity Replica Architecture

We chose to build a 100% pixel-perfect, animation-identical replica of [gravity-design.de](https://gravity-design.de/) using Astro, vanilla CSS, Lenis 1.1, and GSAP 3.12, rather than using heavy UI frameworks or generic starter templates. This decision preserves authentic proprietary `MG12` typography, Newtonian gravitational physics, dual-layer 3D CSS perspective spaces, and zero-runtime-overhead static generation.
